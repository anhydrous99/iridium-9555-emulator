Keyboard controls↗

Digits, *, #, and ↑/↓ match the handset. Esc ends, C calls, P powers, F1/F2 are soft keys, PgUp/PgDn adjust volume, and G presses the convenience key. S presses the 9575 SOS key. No emergency message or call leaves this emulator. After experimental application initialization, mapped keys call the original firmware handler; the input status reports whether each event was delivered. Electrical keypad wiring remains unresolved.

    04 Model boundaries

    EXPLICIT LIMITS

    This is a partial handset hardware model. Application initialization and software key injection are explicit experimental scenarios.

    • Normal handset startup and electrical keypad delivery remain incomplete.
    • Live display output comes from captured original firmware LCD traffic.
    • The satellite model is independent of the original modem firmware.
    • Hardware timing, DSP behavior, and radio protocols are not validated.
